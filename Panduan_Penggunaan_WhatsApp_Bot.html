Panduan Penggunaan WhatsApp Bot Otomasi Foto Studio

Otomasi Pencatatan Jam Masuk: WhatsApp Group → PythonAnywhere Webhook → Google Spreadsheet
Gateway: Green-API (WhatsApp Instance) Server Webhook: PythonAnywhere Flask (tommyidwx) Database: Google Spreadsheet (History Foto Studio) Pembaruan: Oktober 2026

1. Ringkasan & Latar Belakang Sistem

Sebelumnya, setiap jam tangan titipan yang baru tiba di kantor harus dicatat secara manual oleh admin dengan membaca pesan WhatsApp satu per satu dan menyalin data (tanggal, foto, caption, serial number) ke Google Spreadsheet History Foto Studio. Proses manual ini memakan waktu dan berisiko terjadi kesalahan ketik (*human error*).

Dengan sistem WhatsApp Bot Otomasi ini, siapa pun staf atau owner di grup WhatsApp cukup mengirimkan foto jam tangan dengan caption format standar. Dalam hitungan 2-3 detik, sistem otomatis mengekstrak informasi dan membuat baris baru di Spreadsheet dengan format rapi (termasuk foto dan Dropdown Chip biru On Draft) secara otomatis dan hening (Silent Mode tanpa notifikasi balasan di grup).

Siklus Otomasi End-to-End (Tertutup & Terintegrasi):
1. Input Jam Datang: Staf kirim foto + caption di WA → Bot otomatis mencatat di Spreadsheet (Status: On Draft, Mode Hening).
2. Proses Foto Studio & Posting: Jam difoto di studio → Di-post ke Blogspot dengan label CONSIGNMENT_PS / FEATURED.
3. Auto-Upload Shopify & Status Publish: Script upload_automation.py mendeteksi artikel Blogspot → Upload ke Shopify → Status di Spreadsheet otomatis berubah menjadi Publish via Webhook!

2. Format Standar Pesan WhatsApp (SOP Pengiriman)

Agar sistem dapat mendeteksi dan mengekstrak data dengan presisi 100%, pesan yang dikirimkan ke WhatsApp wajib memenuhi aturan berikut:

Format Penulisan Caption Wajib (Pemisah Garis Miring / ):
[Nama & Spesifikasi Jam] / [Tahun/Bulan] / [Serial Number] / [Penitip / Toko / Notes]

Contoh-Contoh Pesan Valid yang Sukses Teruji:

  • DJ28 2T Green Satin 10Diamon / 2019 / Z40904H3 / Omni
  • Pepsi jubilee / oct 2018 / U6159217 / pinjem box
  • Omega speedmaster ed white / JAN 2022 / 88702793 / Pak Said
  • Patek Philippe 5711 / 2020 / 1174015/2726257 / Pak Tommy (Format Patek xxx/xxx aman dibaca 1 nilai)
  • Rolex Submariner / 2021 / 123456789012345 / Toko Jam (Serial panjang hingga 24 karakter)
  • Rolex Explorer / 2020 / Omni (Tanpa Serial Number → Otomatis default INPUT-MANUAL)

Aturan Teknis Validasi Serial Number (Revisi Terbaru):

  1. Wajib Melampirkan Foto: Foto jam tangan harus dikirim bersamaan dengan caption (bisa 1 atau beberapa foto; foto pertama akan dijadikan gambar thumbnail di Spreadsheet).
  2. Pemisah Kolom: Sistem menggunakan garis miring dengan spasi ( / ) sebagai pemisah nama jam, tahun, serial, dan penitip.
  3. Fleksibilitas Panjang Serial (1 - 24 Karakter): Sistem kini mendukung serial number pendek hingga panjang (1 - 24 karakter alfanumerik) serta simbol strip (-).
  4. Dukungan Serial Patek Philippe (Format xxx/xxx): Serial number yang mengandung garis miring tanpa spasi (seperti 1174015/2726257) aman dan tetap terbaca sebagai 1 serial number utuh tanpa terpotong.
  5. Default Value INPUT-MANUAL: Jika chat tidak menyertakan serial number (atau ditulis "nyusul" / "belum ada SN"), sistem otomatis menginput INPUT-MANUAL ke Spreadsheet agar admin dapat melengkapinya kemudian.
  6. Mode Hening (Silent Mode): Bot bekerja secara senyap di latar belakang tanpa mengirimkan pesan balasan/feedback ke grup WhatsApp agar obrolan grup tetap rapi dan tidak terganggu.
  7. Obrolan Biasa Aman dari Spam: Chat obrolan santai tanpa foto (seperti "Oke siap mas", "Jam sudah sampai") otomatis diabaikan dan tidak akan masuk ke Spreadsheet.

4. Arsitektur Komponen & Alur Data

1
Pengirim (Staf / Owner di WhatsApp): Mengirim foto jam tangan dengan format caption bergaris miring (/) ke Grup WhatsApp Foto Studio.
2
Gateway WhatsApp (Green-API): Menerima pesan di WhatsApp, mengunggah foto ke CDN terproteksi, lalu mengirimkan notifikasi Webhook JSON ke server PythonAnywhere.
3
Server Webhook (PythonAnywhere Flask): Memvalidasi pesan (memastikan berasal dari grup target dan memuat foto), mengekstrak tanggal, caption, dan Serial Number, lalu mengirimkan payload terstruktur ke Google Apps Script.
4
Google Apps Script & Spreadsheet: Menambahkan baris baru di sheet History Foto Studio, menyalin aturan Dropdown Chip Biru dan format tinggi baris dari baris atasnya, lalu mengembalikan status sukses.
5
Auto-Update oleh upload_automation.py (Tahap Akhir): Saat jam tangan tayang di Blogspot, script otomatis harian mendeteksi Serial Number yang sama dan otomatis mengubah status di Kolom E dari On Draft menjadi Publish.

A. Script Google Apps Script (Di Spreadsheet History Foto Studio)

function getOrCreateFolder(folderName) {
  var folders = DriveApp.getFoldersByName(folderName);
  if (folders.hasNext()) return folders.next();
  return DriveApp.createFolder(folderName);
}

function doPost(e) {
  try {
    var payload = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("History Foto Studio");
    if (!sheet) return ContentService.createTextOutput(JSON.stringify({"status": "error"})).setMimeType(ContentService.MimeType.JSON);

    // 1. UPDATE STATUS JADI 'Publish' (Dari upload_automation.py)
    if (payload.sheet_name === "PHOTO STUDIO" && payload.sku) {
      var data = sheet.getDataRange().getValues();
      var skuDicari = payload.sku.toString().trim().toLowerCase();
      for (var i = 1; i < data.length; i++) {
        if (data[i][3].toString().trim().toLowerCase() === skuDicari) {
          if (payload.status) sheet.getRange(i + 1, 5).setValue(payload.status);
          return ContentService.createTextOutput(JSON.stringify({"status": "success", "row": i + 1})).setMimeType(ContentService.MimeType.JSON);
        }
      }
    }

    // 2. INPUT BARIS BARU 'On Draft' DENGAN ARSIP PERMANEN GOOGLE DRIVE
    if (payload.action === "insert_draft") {
      var formulaImage = "";
      if (payload.image_url) {
        try {
          var folder = getOrCreateFolder("Arsip Foto Studio WA");
          var blob = UrlFetchApp.fetch(payload.image_url).getBlob();
          var timeStr = Utilities.formatDate(new Date(), "GMT+7", "yyyyMMdd_HHmmss");
          var fileName = (payload.serial_number || "NO-SN") + "_" + timeStr + ".jpg";
          blob.setName(fileName);
          var driveFile = folder.createFile(blob);
          driveFile.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
          var permanentUrl = "https://lh3.googleusercontent.com/d/" + driveFile.getId();
          formulaImage = '=IMAGE("' + permanentUrl + '")';
        } catch (imgErr) {
          formulaImage = '=IMAGE("' + payload.image_url + '")';
        }
      }

      sheet.appendRow([payload.tanggal, formulaImage, payload.name_in_creative, payload.serial_number, "On Draft", payload.notes]);

      var newRow = sheet.getLastRow();
      var prevRow = newRow - 1;
      if (prevRow >= 2) {
        var prevRange = sheet.getRange(prevRow, 1, 1, 6);
        var newRange = sheet.getRange(newRow, 1, 1, 6);
        prevRange.copyTo(newRange, SpreadsheetApp.CopyPasteType.PASTE_FORMAT, false);
        prevRange.copyTo(newRange, SpreadsheetApp.CopyPasteType.PASTE_DATA_VALIDATION, false);
        sheet.setRowHeight(newRow, sheet.getRowHeight(prevRow));
      }
      sheet.getRange(newRow, 5).setValue("On Draft");
      return ContentService.createTextOutput(JSON.stringify({"status": "success", "row": newRow})).setMimeType(ContentService.MimeType.JSON);
    }
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({"status": "error", "message": err.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}

B. Script Logika Ekstraksi Serial Number (flask_app.py di PythonAnywhere)

def parse_parts(caption):
    # Memisahkan caption dengan aman tanpa memotong serial Patek (format xxx/xxx)
    if re.search(r'\s+/\s*|\s*/\s+', caption):
        return [p.strip() for p in re.split(r'\s+/\s*|\s*/\s+', caption) if p.strip()]
    else:
        protected = re.sub(r'(\b\d{5,9})/(\d{5,9}\b)', r'\1__SLASH__\2', caption)
        return [p.replace('__SLASH__', '/').strip() for p in protected.split('/') if p.strip()]

def ekstraksi_serial_number(caption):
    if not caption:
        return "INPUT-MANUAL"
    parts = parse_parts(caption)
    candidates = []
    for idx, part in enumerate(parts):
        clean = part.strip()
        if ' ' in clean or any(bw in clean.lower() for bw in BLACKLIST_WORDS):
            continue
        if MONTH_YEAR_REGEX.search(clean) and not ('/' in clean and len(clean) >= 10):
            continue
        if re.match(r'^[A-Za-z0-9/-]{1,24}$', clean):
            score = 10 + (20 if idx == 2 else 0) + (30 if '/' in clean else 0)
            if re.search(r'[A-Za-z]', clean) and re.search(r'[0-9]', clean):
                score += 15
            candidates.append((score, clean.upper()))
    if candidates:
        candidates.sort(key=lambda x: x[0], reverse=True)
        return candidates[0][1]
    return "INPUT-MANUAL"

7. Panduan Pemecahan Masalah (Troubleshooting)

1. Foto atau Data Tidak Masuk ke Spreadsheet Saat Chat Dikirim

Langkah Pengecekan:
  1. Pastikan status instance di dashboard Green-API berstatus `authorized` (ikon hijau). Jika logout, scan ulang QR code.
  2. Periksa bagian Webhooks di Green-API: pastikan toggle Receive webhooks on incoming messages and files dalam keadaan ON (Hijau) dan URL sudah benar (https://tommyidwx.pythonanywhere.com/wa-webhook).
  3. Buka tab Web di PythonAnywhere → klik link Server log untuk memeriksa apakah paket data WhatsApp masuk dan berhasil di-forward (HTTP 200).

2. Kolom Status Berupa Teks Biasa (Bukan Dropdown Chip Biru)

Solusi: Pastikan di Google Apps Script Anda telah melakukan Deploy → Manage deployments → Edit (✏️) → Version: New version → Deploy. Fitur penyalinan Dropdown Chip baru akan aktif pada versi script terbaru.

3. Cara Mengetahui atau Membatasi ID Grup WhatsApp (TARGET_GROUP_ID)

Jika di masa depan Anda ingin membatasi agar bot HANYA merespons satu grup tertentu:

  1. Kirim satu pesan apa saja di grup WhatsApp target Anda.
  2. Buka tab Web di PythonAnywhere → buka Server log.
  3. Cari baris yang bertuliskan: 📡 Event Chat ID: 120363xxxxxx@g.us.
  4. Salin kode tersebut dan masukkan ke variabel TARGET_GROUP_ID = "120363xxxxxx@g.us" pada file flask_app.py, lalu klik Save dan Reload web app.
