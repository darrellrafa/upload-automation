2. Kapan Harus Menggunakan Google Colab?

Script notebook di Google Colab sangat ideal digunakan dalam kondisi:

  • Upload Batch Manual: Anda ingin mengunggah beberapa link artikel lama atau artikel tertentu sekaligus tanpa menunggu giliran monitoring otomatis 5 menit.
  • Re-upload Terarah: Ada postingan tertentu yang sempat gagal di-upload di server atau ingin diulang dengan format spesifik.
  • Pemeriksaan & Debugging Langsung: Menampilkan log proses langkah demi langkah secara visual di browser Anda secara instan.

4. Panduan Langkah Demi Langkah di Google Colab

1
Buka Google Colab & Upload Notebook:
  1. Buka browser dan kunjungi: https://colab.research.google.com
  2. Login dengan akun Google Anda.
  3. Pada pop-up jendela yang muncul, pilih tab Upload (Unggah).
  4. Klik tombol Choose File / Browse dan pilih file .ipynb yang sesuai (misal: auto_upload_photo_studio_(google_oauth).ipynb).
2
Hubungkan Runtime (Connect):

Di pojok kanan atas layar Google Colab, klik tombol Connect (Hubungkan). Tunggu beberapa detik sampai muncul indikator RAM dan Disk berwarna hijau.

3
Masukkan Link Blogspot yang Ingin Di-Upload:

Di dalam code cell, cari baris DAFTAR_URL_BLOGSPOT = [ ... ]. Masukkan link artikel Blogspot di dalam tanda kutip dua. Anda bisa memasukkan 1 link atau lebih (pisahkan dengan koma): 

DAFTAR_URL_BLOGSPOT = [
    "https://www.dualtime.id/2026/10/for-sale-rolex-submariner-date.html",
    "https://www.dualtime.id/2026/10/for-sale-patek-philippe-aquanaut.html"
]
4
Pastikan Dependensi Terinstal (Cell Pip Install):

Pastikan baris instalasi library di bagian paling atas sudah aktif: 

!pip install requests beautifulsoup4 google-api-python-client

Catatan: Jika ada tanda pagar (#) di depan perintah di atas, hapus tanda pagarnya agar library terpasang di runtime Colab.

5
Jalankan Script (Run):

Untuk mengeksekusi proses upload:

  • Klik tombol Play (▶️) di sebelah kiri code cell tersebut, ATAU
  • Tekan kombinasi tombol Shift + Enter pada keyboard Anda, ATAU
  • Klik menu Runtime di toolbar atas → pilih Run all (Ctrl + F9 / Cmd + F9).
6
Amati Log Proses di Bawah Cell:

Script akan menampilkan log eksekusi secara real-time. Pastikan Anda melihat indikator sukses berikut:

5. Tips & Trik Penggunaan di Google Colab

1. Menjalankan Banyak Link Sekaligus:
Anda bebas memasukkan 10, 20, atau lebih link di array DAFTAR_URL_BLOGSPOT. Script akan memprosesnya satu per satu secara berurutan lengkap dengan progress counter [1/10], [2/10], dst.
2. Format Penulisan Link yang Benar:
Setiap link wajib diawali dengan https://, diapit tanda kutip ("..." atau '...'), dan diakhiri dengan koma (,) jika ada link berikutnya.
3. Runtime Disconnected / Timeout:
Google Colab akan otomatis memutus sesi (disconnect) jika tab browser ditutup atau idle dalam waktu lama. Jika status di pojok kanan atas berubah menjadi Disconnected, cukup klik Reconnect dan jalankan kembali cell.

6. Pemecahan Masalah (Troubleshooting Colab)

A. Error: ModuleNotFoundError: No module named 'googleapiclient'

Solusi: Jalankan perintah pip install terlebih dahulu di cell paling atas: !pip install requests beautifulsoup4 google-api-python-client, lalu jalankan ulang kode script Anda.

B. Error: invalid_grant: Token has been expired or revoked

Status Saat Ini (Sudah Teratasi): Token Google OAuth pada seluruh notebook saat ini sudah berstatus In Production dan bersifat permanen (tidak akan expired 7 hari).

Catatan: Jika di kemudian hari akses Google dicabut manual (revoked) atau berpindah project GCP, buat token baru via Google OAuth Playground dengan project yang berstatus In Production, lalu perbarui variabel GCP_REFRESH_TOKEN.

C. Error: Token akses gagal didapatkan / 401 Unauthorized Shopify

Penyebab: Kredensial API Shopify (Client ID / Client Secret) salah atau koneksi terputus.

Solusi: Periksa kembali variabel CLIENT_ID dan CLIENT_SECRET di bagian konfigurasi Shopify. Pastikan nilainya sama dengan yang ada di Shopify App Developer Dashboard Anda.

D. Merek (Vendor) Salah Terdeteksi / Belum Terdaftar

Tanda & Penyebab: Produk ter-upload tetapi kolom Vendor di Shopify salah atau terpotong kata pertamanya. Penyebab utamanya adalah merek tersebut belum ada di dictionary DAFTAR_MEREK_IDWX pada notebook yang Anda jalankan.

Langkah Penanganan:

  1. Tambahkan Merek di Notebook: Di dalam notebook Colab (pada Section 1), cari variabel DAFTAR_MEREK_IDWX, lalu tambahkan baris merek baru dengan format: 
    "NAMA MEREK KAPITAL": "Nama Merek Resmi",
# Contoh:
"GIRARD PERREGAUX": "Girard-Perregaux",
"ORIS": "Oris",
    Pastikan sisi kiri huruf kapital semua, dan sisi kanan adalah nama resmi vendor untuk Shopify.
  2. Update Manual di Shopify untuk Produk yang Sudah Ter-upload:
    Untuk produk yang sudah telanjur ter-upload dengan merek yang salah, script tidak akan mengupdate produk lama di Shopify secara otomatis. Silakan buka Shopify Admin → Products, buka produk tersebut, lalu ubah kolom Vendor di panel kanan secara manual dan klik Save.

7. Perbedaan Alur: Google Colab vs PythonAnywhere

Aspek Google Colab (.ipynb) PythonAnywhere (.py)
Mode Operasi Manual / On-Demand (dijalankan saat user menekan Play). Otomatis 24/7 (berjalan di background tanpa campur tangan user).
Sumber Input URL Diisi manual oleh user di array DAFTAR_URL_BLOGSPOT. Mengekstrak otomatis postingan baru hari ini via Blogger API.
Klasifikasi Tipe User memilih notebook yang sesuai secara manual. Script mengklasifikasi label secara otomatis di 1 file.
Kebutuhan Tab Browser Tab Google Colab harus tetap terbuka selama proses upload berlangsung. Komputer & browser bisa dimatikan (berjalan di cloud server).
