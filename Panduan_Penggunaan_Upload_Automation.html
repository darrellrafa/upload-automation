Panduan Praktis Upload Automation

Otomasi Sinkronisasi Jam Tangan: Blogspot (Dualtime ID) → Website Shopify & YouTube Shorts
File Utama: upload_automation.py Server Otomasi: PythonAnywhere (Always-on Task) / Google Colab Terhubung ke: Shopify Store, Blogger API, & YouTube Data Versi Panduan: November 2026

1. Mengenal Cara Kerja Upload Automation

Sistem Upload Automation bekerja seperti asisten otomatis di balik layar. Setiap 5 menit sekali, sistem mengecek postingan jam tangan baru di blog dualtime.id (Google Blogger). Begitu mendeteksi artikel jam baru, sistem langsung mengekstrak data penting (Merek, Judul, SKU, Harga Jual, Tahun, Spesifikasi, Kondisi, Foto High-Resolution), lalu mengunggahnya secara otomatis menjadi produk siap jual di Shopify Store serta menjadwalkan video promosi ke YouTube Shorts.

Alur Kerja Otomatis Setiap 5 Menit:
Blogger API → Cek Jam Baru Masuk → Klasifikasi Kategori (PS, PO, FEATURED, TWP, NOTSYNC) → Ambil Foto Kualitas Tinggi & Detail Produk → Unggah ke Shopify → Cek Ulang Jumlah Foto (Auto-Reconcile) → Update Status Spreadsheet → Jadwalkan Video YouTube Shorts → Catat ke processed_urls.json.

2. Logika Klasifikasi Kategori Jam Tangan

Setiap artikel Blogspot yang terdeteksi akan diperiksa label dan formatnya untuk menentukan perlakuan upload yang tepat:

Format / Kategori Kriteria Deteksi (Blogger) Perlakuan Shopify Integrasi Spreadsheet
PHOTO STUDIO Label memuat CONSIGNMENT_PS Tags: __label2:Consignment, TitipIDWX, Gender Tag (Men/Ladies). Lokasi stok: Blok M Plaza. Update status Publish di Spreadsheet History Foto Studio via Webhook.
FEATURED Label memuat FEATURED Tags: Hanya Gender Tag (Men/Ladies). Lokasi stok: Blok M Plaza. Kirim data produk baru ke Spreadsheet Slow Moving (Tab ALL STOCK / NEW ARRIVAL).
PHOTO OWNER Label memuat CONSIGNMENT_PO (atau awalan SKU CPO). Tags: TitipOwner. Lokasi stok: OWNER (S). Mencentang kolom WEB di Spreadsheet Owner (Tab PHOTO OWNER) via Webhook.
NOTSYNC Label memuat NOTSYNC. Tags: NotSync. Stok lokasi: Blok M Plaza. Tidak memicu webhook spreadsheet.
TWP Label memuat TWP (The Watch Project). Tags: SG. Stok lokasi: Blok M Plaza. Tidak memicu webhook spreadsheet.

3. Fitur Unggulan & Perlindungan Otomatis

1
Ekstraksi Harga Cerdas (Anti Salah Ambil Retail Price): Pada jam tangan mewah, deskripsi sering menyertakan harga butik resmi (contoh: Retail Price: IDR 500) di atas harga jual toko kita (Price: Rp 248,000,000). Sistem kini menggunakan filter khusus yang hanya membaca kata Price di awal baris dan mengabaikan baris Retail Price 100%. Harga yang masuk ke Shopify dijamin 100% harga jualan resmi toko.
2
Otomatis Siapkan Video YouTube Shorts: Jika artikel Blogspot mencantumkan tautan Google Drive aset jam tangan, script otomatis mendeteksi file video *shorts*.mp4 di folder tersebut. Video akan digabungkan dengan musik latar yang pas dari koleksi audio Google Drive, lalu otomatis diunggah ke YouTube Shorts.
3
Download Foto Lengkap & Cek Ulang Otomatis (Auto-Reconcile): Sistem selalu mengambil foto resolusi tertinggi dari blog. Begitu produk selesai dibuat di Shopify, sistem menghitung kembali kelengkapan fotonya. Jika ada foto yang sempat tertinggal akibat gangguan jaringan sesaat, sistem akan mengunggah ulang foto tersebut seketika.
4
Perpanjangan Token Shopify Otomatis 24 Jam: Koneksi Shopify diperiksa secara berkala. Jika masa berlaku token hampir habis, sistem langsung memperpanjang aksesnya sendiri di latar belakang tanpa mengganggu jalannya proses upload.
5
Penomoran SKU & URL Anti-Bentrok: Jika ada barang titipan lama dengan nomor SKU yang sama, sistem menambahkan penomoran unik (-1, -2) agar data produk tidak saling tumpang tindih.

4. Panduan Menjalankan Sistem

A. Mode Otomatis 24 Jam (PythonAnywhere Always-on Task)

Script akan terus memantau blogspot setiap 5 menit tanpa perlu intervensi manual:

  1. Login ke dashboard PythonAnywhere.
  2. Buka tab Tasks → bagian Always-on tasks.
  3. Perintah yang aktif: 
    python3.10 /home/username/upload_automation.py
  4. Status task harus berikon hijau Running. Klik ikon kertas untuk memantau log aktivitas real-time.

B. Mode Manual On-Demand (Google Colab Notebooks)

Jika ada artikel lama yang ingin diunggah secara khusus tanpa menunggu antrian otomatis, gunakan 4 file notebook Colab:

  • auto_upload_photo_studio_(google_oauth).ipynb → Format Photo Studio & Featured.
  • auto_upload_photo_owner_(google_oauth).ipynb → Format Photo Owner (CPO).
  • upload_otomasi_format_notsync_(google_oauth).ipynb → Format NotSync.
  • auto_upload_twp_(google_oauth).ipynb → Format TWP (The Watch Project).

5. Memahami File Pelacak Status (Cache JSON)

Nama File Fungsi & Kegunaan
processed_urls.json Menyimpan seluruh URL artikel Blogspot yang sudah sukses di-upload. Selama link ada di file ini, script tidak akan memproses ulang artikel tersebut (mencegah duplikasi).
processed_skus.json Menyimpan daftar SKU yang diproses pada hari ini untuk mencegah postingan ganda pada tanggal yang sama.
pending_youtube_queue.json Menyimpan daftar antrean video YouTube Shorts yang sedang atau belum diunggah dari Google Drive.

6. Panduan Pemecahan Masalah (Troubleshooting)

Kendala Penyebab Solusi
Harga jam di Shopify keliru mengambil angka Retail Price Menggunakan script lama yang membaca kata Price pertama. Gunakan versi terbaru upload_automation.py. Script sudah otomatis mengabaikan Retail Price dan mengambil baris harga jual resmi.
Error: invalid_grant: Token has been expired Refresh token Google OAuth dicabut atau diganti di akun Google. Lakukan exchange authorization code baru via Google OAuth 2.0 Playground dan perbarui variabel GCP_REFRESH_TOKEN pada file .env.
Merek (Vendor) jam salah / menjadi Unknown Nama merek jam tangan belum terdaftar pada dictionary DAFTAR_MEREK_IDWX di dalam script. Tambahkan keyword merek pada DAFTAR_MEREK_IDWX di upload_automation.py (Key dalam huruf kapital, Value dalam format nama resmi).
Video Shorts tidak terunggah ke YouTube FFMPEG belum terpasang atau folder Google Drive tidak memiliki video dengan penamaan *shorts*.mp4. Pastikan FFMPEG tersedia di PATH sistem dan nama file video di Google Drive memuat kata shorts.
